# Hanu S Kumar — Portfolio (Cockpit edition)

Car-themed full-stack developer portfolio built with **React + Vite**: ignition preloader, animated dashboard gauges, a car driving on a live road, a gear indicator that follows your scroll, a route-style experience timeline and a push-to-start contact button.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
```

## Edit the content

Everything (bio, stats, experience, skills, links) lives in [`src/data.js`](src/data.js). Résumé PDF: `public/Hanu_S_Kumar_Resume.pdf`.

## Deploy to Vercel

Import this repo at vercel.com/new — Vercel auto-detects Vite (build `npm run build`, output `dist`).
